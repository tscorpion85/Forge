# Small Worlds

The first experiment in Forge: a tiny landscape you can shape and watch evolve.

Open `index.html` in a modern browser. Paint grass, trees, water, stone, fire, or bare soil. Water encourages growth; fire spreads through vegetation and follows the wind; rain dampens it. Pause time, choose a wind direction, change its speed, generate another landscape, or save a PNG snapshot. Pointer controls work with a mouse, pen, or touch screen.

There are no dependencies, accounts, tracking scripts, network requests, or build steps. The world lives only in the open tab. Each new world starts with a random landscape.

Forge is an open-ended collection of playable experiments. This is experiment 001.
